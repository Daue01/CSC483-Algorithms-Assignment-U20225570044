# Algorithms Analysis and Design - Refactored Assignment

## Requirements
- **Java:** JDK 11+
- **Build:** Maven
- **Tests:** JUnit 5.10.0

## Execution Commands
**Search Performance Evaluation:**
`mvn exec:java -Dexec.mainClass=lookup.SearchPerformanceRunner`

**Sorting Algorithms Experiment:**
`mvn exec:java -Dexec.mainClass=ordering.SortExperiment`

**Run Test Suite:**
`mvn test`
